# API Bibliothèque universitaire

API REST (Node.js, Express, SQLite) avec intégration OpenAI (résumés, recherche intelligente), Stripe (abonnement premium) et webhooks.

## Installation
```bash
npm install
Creer .env   # puis remplir les clés
npm start
```
API : http://localhost:3000

## Documentation et tests
- `openapi.yaml` : spécification OpenAPI
- `bibliotheque.postman_collection.json` : tests Séance 3
- `bibliotheque_seance6.postman_collection.json` : tests Séance 6
Lancer chaque collection avec Run collection, dans l'ordre.
